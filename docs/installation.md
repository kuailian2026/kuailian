# 快连下载安装指南

快连支持多种常见设备。不同平台的安装方式和系统要求有所区别，因此下载安装前，建议先确认当前使用的设备和系统版本。

本页面主要整理 **Windows、macOS、Android 和 iOS** 的安装流程，并补充首次安装过程中比较容易遇到的问题。

---

## 快连支持哪些平台？

目前可以根据设备选择对应的版本：

| 平台      | 适用设备           | 安装方式         |
| ------- | -------------- | ------------ |
| Windows | Windows 电脑     | 安装程序         |
| macOS   | MacBook、iMac 等 | macOS 安装包    |
| Android | Android 手机和平板  | APK / 对应应用渠道 |
| iOS     | iPhone、iPad    | 对应 iOS 安装渠道  |

如果不确定应该下载哪个版本，建议先查看设备的系统信息，再选择对应安装文件。

---

## 下载快连

快连相关版本可以通过项目的 [Releases](https://github.com/kuailian2026/kuailian/releases) 页面查看。

进入 Releases 后，可以根据版本号和文件名称判断适合当前设备的安装包。

**Windows：**

选择 Windows 对应的安装文件。

**macOS：**

选择适用于 Mac 的安装文件，并注意设备处理器架构。

**Android：**

根据设备情况获取对应 Android 安装文件。

**iOS：**

iPhone 和 iPad 用户根据实际地区和可用渠道查看对应的安装方式。

> 下载和安装软件时，建议确认文件来源以及版本信息，不要随意使用来源不明的安装包。

---

# Windows 安装教程

## 1. 下载 Windows 版本

打开 [快连 Releases](https://github.com/kuailian2026/kuailian/releases)，找到需要安装的版本。

选择 Windows 对应的安装文件。

下载完成后，可以先检查文件是否已经完整下载。

---

## 2. 开始安装

双击下载好的安装程序，根据 Windows 安装向导完成后续操作。

通常情况下，只需要按照安装程序的提示逐步进行即可。

如果系统出现权限确认提示，需要根据当前电脑的安全设置进行确认。

---

## 3. 启动快连

安装完成后，从桌面快捷方式或系统应用列表启动快连。

第一次启动时，可以先不要修改大量高级设置。

建议按照：

```text
启动客户端
    ↓
检查基础设置
    ↓
建立连接
    ↓
等待连接状态稳定
    ↓
打开浏览器测试
```

完成第一次连接。

---

# macOS 安装教程

## 1. 确认 Mac 类型

安装前可以先确认自己的 Mac 使用哪种处理器。

常见设备包括：

* Apple Silicon
* Intel

如果 Releases 中存在不同架构的版本，应选择与当前设备匹配的安装包。

---

## 2. 下载 macOS 版本

进入 [快连 Releases](https://github.com/kuailian2026/kuailian/releases)，找到对应的 macOS 版本。

下载完成后打开安装文件。

---

## 3. 完成安装

根据 macOS 的安装提示完成操作。

首次运行应用时，如果系统出现安全提示，不需要反复重新下载安装。

可以先查看：

**系统设置 → 隐私与安全性**

确认系统是否阻止了应用启动。

---

## 4. 第一次运行

启动快连后，先完成必要的基础设置，然后尝试建立连接。

如果能够正常连接，可以再根据自己的实际需求调整其他选项。

---

# Android 安装教程

## 1. 确认设备环境

安装前建议检查：

* Android 系统版本
* 设备剩余存储空间
* 当前网络状态
* 安装文件来源

确保设备有足够空间完成安装。

---

## 2. 获取 Android 版本

可以通过 [Releases](https://github.com/kuailian2026/kuailian/releases) 查看项目整理的版本信息。

如果使用 APK 安装方式，应特别注意安装文件来源和完整性。

---

## 3. 安装应用

获取对应安装文件后，根据 Android 系统提示完成安装。

如果系统提示需要允许来自特定来源的应用安装，应先确认安装文件来源可靠，再根据系统提示操作。

---

## 4. 首次启动

安装完成后打开快连。

首次启动时按照应用提示完成必要设置，然后进行一次连接测试。

如果连接正常，可以继续正常使用。

---

# iOS 安装教程

iOS 的应用安装方式与 Windows、macOS 和 Android 不同。

iPhone 或 iPad 用户应根据当前所在地区和实际可用渠道获取对应版本或安装说明。

安装完成后：

1. 打开快连。
2. 查看首次启动提示。
3. 根据系统提示完成必要设置。
4. 进入连接页面。
5. 尝试建立第一次连接。
6. 打开浏览器检查网络状态。

如果无法正常安装或启动，可以先检查当前 iOS 版本以及应用来源。

---

# 安装完成后应该做什么？

软件安装完成后，建议先进行一次基础检查。

### 第一步：确认客户端能够启动

如果应用能够正常打开，说明最基础的安装流程已经完成。

### 第二步：确认本地网络正常

在建立连接前，可以先确认当前 Wi-Fi 或移动网络能够正常使用。

### 第三步：建立第一次连接

完成基础设置后尝试连接。

### 第四步：测试网络

连接成功后，可以打开浏览器访问几个普通网页，确认网络是否正常。

# 安装过程中常见问题

## 安装文件打不开

如果下载后无法运行，可以先检查：

* 文件是否完整下载
* 文件格式是否正确
* 当前系统是否兼容
* 系统安全设置是否阻止运行

不要因为一次启动失败就连续下载多个来源不明的安装包。

---

## Windows 安装后无法启动

可以先重新启动电脑，然后再次运行客户端。

如果仍然无法启动，可以检查 Windows 安全设置以及系统中是否存在其他网络类软件产生冲突。

---

## macOS 提示无法打开

macOS 对应用来源有额外的安全检查。

如果确认应用来源可靠，可以进入：

**系统设置 → 隐私与安全性**

查看是否存在相关的应用启动提示。

---

## Android 无法安装 APK

首先检查 APK 是否完整，以及当前 Android 系统是否允许安装该来源的应用。

如果设备提示版本不兼容，则需要确认当前 APK 是否适用于你的 Android 系统。

---

## iOS 找不到应用

iOS 应用的可用渠道可能受到地区、商店账号以及当前版本情况影响。

建议根据实际地区查看对应的安装说明，而不是随意安装来源不明的文件。

---

# 安装后无法连接怎么办？

如果客户端能够正常打开，但是第一次连接失败，那么问题通常已经从“安装问题”变成了“连接问题”。

可以先检查：

1. 当前设备是否正常联网。
2. 是否同时运行其他网络代理工具。
3. 是否存在系统网络配置冲突。
4. 是否可以切换其他 Wi-Fi 或移动网络进行测试。
5. 重启客户端后是否恢复正常。

进一步排查可以查看：

[快连连接失败怎么办](connection-failed.md)

---

# 连接成功但无法上网怎么办？

如果客户端已经显示连接成功，但浏览器仍然无法正常访问网页，可以先关闭浏览器后重新打开。

如果问题继续存在，可以检查系统中的其他代理或网络工具。

也可以尝试：

```text
关闭其他网络工具
       ↓
重新启动快连
       ↓
重新建立连接
       ↓
打开浏览器测试
```

如果仍然无法解决，可以继续查看：

[快连网络异常处理](network-problem.md)

# 快连速度慢怎么办？

安装完成以后，如果发现网络速度不理想，不建议立即重新安装客户端。

网络速度可能受到多个因素影响，例如：

* Wi-Fi 信号
* 移动网络质量
* 本地宽带
* 网络延迟
* 网络拥塞
* 丢包情况
* 当前网络环境

可以先测试不使用快连时的网络状态，再进行连接后的对比。

详细排查：

[快连速度慢怎么解决](slow-speed.md)
