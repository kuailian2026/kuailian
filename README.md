## 🔧 常见问题

### 快连连接不上怎么办？

首先检查当前网络是否正常，然后重新打开客户端并再次尝试连接。如果其他网络也存在相同问题，可以进一步检查系统网络设置。

### 快连连接后无法上网怎么办？

可以先确认系统是否存在其他代理、网络加速器或安全软件造成的冲突，再重新建立连接。

### 快连速度变慢怎么办？

网络速度会受到本地 Wi-Fi、移动网络、线路延迟以及当前网络环境等因素影响。建议先测试本地网络，再判断是否属于连接线路问题。

### 快连频繁断开怎么办？

可以观察问题是否只发生在某一个网络环境。如果切换 Wi-Fi、移动网络后表现不同，通常需要分别排查本地网络稳定性和客户端连接状态。
